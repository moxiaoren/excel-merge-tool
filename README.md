# Excel 表格合并工具（行匹配版）

纯前端 Excel 表格合并工具，支持多文件上传（xlsx/xls/csv）、人员过滤、列映射（目标列 + 多源列）、预设映射、按行合并导出。数据全程本地处理，无后端、无上传。

## 功能
- 多文件上传：xlsx / xls / csv
- 人员过滤：名单管理，按合并字段过滤
- 列映射：目标列 + 多源列，支持点选、拖拽、下拉补挂
- 预设映射：字段模板 / 映射方案两套预设，可保存与管理
- 映射预览：合并前可视化检查匹配与留空
- 按行合并导出：日期格式化、extractChineseName、备注截断等
- 本地持久化：人员名单、当前映射、自定义预设存于 localStorage

## 使用
直接打开 `index.html` 即可（或访问 GitHub Pages 在线版）。

> 本项目为纯前端工具，所有数据仅在你本地浏览器处理。
